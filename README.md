# Anakin's Matrix · 个人技术作品与服务矩阵

高颜值现代 Bento Grid 风格的个人聚合门户站点。

## 聚合服务
- **Anakin IoT 工业物联网平台**: 设备物模型、规则引擎、OTA、实时遥测
- **工业 AI 智能助手**: 赣鄱词元 DeepSeek 大模型驱动的运维 Agent
- **MovieHub 影视中心**: 多源流媒体内容聚合
- **MyMem 智能记忆**: 向量长期记忆库
- **Password Vault 保险库**: 端到端加密凭据中心

## 技术架构
- 纯前端单页架构（零构建、秒开、毫秒级响应）
- 现代玻璃拟态（Glassmorphism）与流光动效
- 部署于 Render 全球免费静态托管 CDN
